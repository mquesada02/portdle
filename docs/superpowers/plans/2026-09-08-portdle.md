# Portdle Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the v1 Portdle static SPA: three UTC Dailies (name → port), Blitz (default and inverted), personal stats, History, GitHub Pages.

**Architecture:** Pure TypeScript engine (guess, Daily lookup, Blitz reducer, streaks, search, schedule generator) with no DOM. Thin React UI. Catalogs and committed schedules as JSON. `localStorage` adapter. TanStack Router, path URLs, Vite `base: '/portdle/'`.

**Tech Stack:** React 19, Vite, TypeScript (`strict` + `noUncheckedIndexedAccess`), Tailwind v4, Biome, Vitest, Testing Library, TanStack Router (code-based), pnpm.

**Spec:** `docs/superpowers/specs/2026-09-08-portdle-design.md`

## Global Constraints

- pnpm only; pin `packageManager`; `.npmrc` `strict-peer-dependencies=true`
- TypeScript `strict` and `noUncheckedIndexedAccess`
- Biome lint+format; unused and `any` are errors
- Closed unions only: `DailyCategory = "mixed" | "protocols" | "applications"`; `Orientation = "default" | "inverted"`; `BlitzMode = "sprint" | "marathon" | "survival"`; `CatalogKind = "protocol" | "application"`
- `engine/` must not import React, `document`, or `localStorage`
- English UI; no PWA, no analytics, no backend
- Vite `base: '/portdle/'`; GitHub Pages at `/portdle/`
- Epoch UTC date `2026-09-09` until first public Daily
- Tests use Vitest; no Playwright in v1
- Commit messages: conventional, no AI trailers

### Task 5: Default guess

**Files:**
- Create: `src/engine/guess.ts`, `src/engine/guess.test.ts`

**Interfaces:**
- Consumes: `GuessResult`, `entriesForPort`
- Produces:

```ts
export function digitLength(port: number): number;
export function parsePortDigits(digits: string): number | "incomplete" | "invalid";
export function evaluateDefaultGuess(input: {
  digits: string;
  answer: CatalogEntry;
  previousPorts: number[];
  catalog: CatalogEntry[];
}): GuessResult;
```

`digitLength`: `String(port).length` (port is already without leading zeros).

`parsePortDigits`: if `digits` is empty or has a non-digit → `"incomplete"` if empty/`length < digitLength` is **not** this function’s job — `evaluateDefaultGuess` treats empty/non-digit as `invalid`. Spec: incomplete / non-digits → invalid. So: if `!/^\d+$/.test(digits)` → caller returns invalid. `parseInt(digits, 10)`; if `> 65535` invalid; else the integer (leading zeros collapse).

Identified: among `entriesForPort(catalog, n)`, sort by `id`, take `[0]`, map to `Identified`. Include retired.

```ts
export function evaluateInvertedGuess(input: {
  id: string;

  previousIds: string[];
```

Search: empty/whitespace query → `[]`. Tokens = `[name, ...aliases].map(t => t.toLowerCase())`. Match if any token `startsWith` trimmed lower query. Sort: name-prefix first, then alias-prefix, then `name.localeCompare`. Cap 20. Description not indexed.

```yaml
name: CI
on:
  push:
    branches: [master]
  pull_request:
jobs:
  build:
    runs-on: ubuntu-latest
    permissions:
      contents: read
      pages: write
      id-token: write

      - uses: pnpm/action-setup@v4

      - run: pnpm test
      - run: pnpm gen:schedule --check

    runs-on: ubuntu-latest
    permissions:
      pages: write
      id-token: write

    steps:
```
